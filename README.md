# ⚔️ CardGameMaker · 类三国杀卡牌游戏

一个可自定义武将/技能的类三国杀卡牌游戏：内置完整对局引擎、AI、联机、手机适配、三国杀式牌桌与墨玉鎏金视觉。既可以用模板生成，也可以让 AI 生成技能代码。

> 详细需求、设计结论与进度见 **[PROJECT_BRIEF.md](PROJECT_BRIEF.md)**；桌面也有交接版设定集。

---

## 🚀 快速开始

### 方式一：桌面快捷方式（推荐）

桌面上的 **CardGameMaker** 快捷方式指向 `D:\CardGameMaker\start.bat`，双击会同时启动：
- 游戏网页：`http://localhost:3000`
- 联机中继：`ws://localhost:8787`
- 自动打开浏览器；启动过程写入 `launcher.log`

### 方式二：`start.bat`

```bat
D:\CardGameMaker\start.bat
```

脚本会优先使用 PATH 中的 Node.js，其次使用本机 DSH 自带运行时。

### 方式三：命令行

```bash
cd D:\CardGameMaker
npm install
npm start          # 网页 + 联机中继
npm run dev        # 只启动网页
npm run build      # 生产构建到 dist/
npm run preview    # 本地预览构建产物
```

> 需要 Node.js 18+。手机与电脑联机时，电脑和手机需在同一局域网；联机大厅会显示局域网地址与二维码。

## 🃏 出牌阶段可用性规则

- **【闪】不能主动使用**，只能响应【杀】；
- **【无懈可击】不能主动使用**，在有害锦囊生效前响应；
- **【桃】** 仅受伤时可主动使用；满体力时置灰；
- **【酒】** 每回合限一次，下一张【杀】伤害 +1；
- **【杀】** 需在攻击范围内且未超出次数（咆哮/诸葛连弩不受限）；
- **【顺手牵羊】** 目标距离 1 内且有牌；**【过河拆桥】** 目标有牌；**【兵粮寸断】** 目标距离 1 内；
- 空城角色不能被【杀】【决斗】指定；不可用牌自动置灰；
- 同一判定区不能重复放置同名延时锦囊。

## 🧩 DIY 技能拼装

技能编辑器顶部新增「模块化技能拼装」，不用写代码也能拼技能：

| 模块 | 可选项 |
|------|--------|
| 触发时机 | 出牌阶段开始、受到伤害后、使用牌时、摸牌阶段、回合结束、进入濒死、死亡、回复体力 |
| 发动条件 | 手牌>体力、手牌<体力、已受伤、体力≤X、势力为魏/蜀/吴/群、判定为红色 |
| 发动代价 | 无、弃红牌、弃任意手牌、弃装备、失去1点体力 |
| 执行效果 | 摸X张、回复X点、对攻击范围内角色造成X点伤害、弃目标牌、获得目标牌、令目标交牌否则失去体力、弃自己手牌 |
| 频率限制 | 每回合一次、每阶段一次、不限次数、每局限一次 |

点击「填入技能表单」会把模块自动翻译成：
- 五段式描述：`【触发时机】【发动条件】【发动代价】【执行效果】【频率限制】`
- `filterCode` / `costCode` / `contentCode`
- 技能类型、时机、次数与锁定设置：主动技输出 `enable:'phaseUse'`（不自动触发），触发/锁定技输出 `triggerTiming`；选「受到伤害后」等时机会自动切成触发技，不会再错误地出现在出牌阶段按钮

> 被动技能无需点击：锁定技自动生效；触发技在满足时机时自动触发（可选触发技默认询问，可在设置中改为自动发动）。

内置示例：**烈火**、**青囊**、**铁壁**，点击即可载入并填入表单。

## 🎙️ AI 配音（浏览器 / Piper 离线 / GPT-SoVITS）

**方式 A：浏览器语音**：免配置，直接试听。

**方式 B：Piper 离线（推荐，免费开源、CPU 可跑）**
1. 双击项目根目录 `start-piper.bat`，等待出现 `Piper TTS service on http://127.0.0.1:9881`（约 1~2 秒）
2. 游戏 →「武将编辑器」→「AI 配音」→ 选「Piper 离线（免费开源）」→ 检测服务 → 生成并试听
3. 模型：`voice_service/piper/voices/zh_CN-huayan-medium.onnx`（女声 Huayan / 22050Hz）；Piper MIT，模型仓库 MIT；训练数据集 HuaYan 授权标注 Unknown，商用前请复核
4. 每次请求约 0.5 秒（CPU），关闭窗口即停止

**方式 C：GPT-SoVITS 定制音色**
1. 双击 `start-voice.bat`，等待 `Uvicorn running on http://127.0.0.1:9880`（首次约 40 秒）
2. 选「本地 GPT-SoVITS」→ 生成并试听；参考音频默认 `voice_refs/ref-zh.wav`、文本 `voice_refs/ref-zh.txt`
3. 首次合成约 50 秒预热，之后约 1~2 秒；关闭窗口停止服务（释放显存）

> 三种方式都在本机处理；Piper 完全离线，GPT-SoVITS 也不上传参考音频。

## 📱 手机 APK（电脑生成 · 手机安装）

1. 电脑端首次安装工具链：`npm run apk:setup`（JDK 17 + Android SDK，约 10 分钟）
2. 设置 →「手机 APK」→「生成手机 APK」；约 8 秒生成 `public/apk/CardGameMaker-<版本>.apk`
3. 生成后可下载、复制链接，或用局域网二维码给手机扫码安装；每次发新版本重新点一次即可分享
4. 手机版是独立 WebView APK（内置本地静态服务），支持单机对局、AI 立绘、武将编辑、音效/背景音乐、离线运行
5. **电脑专属功能**：本地 Piper/GPT-SoVITS 配音、本地 Stable Diffusion、PC 文件系统、后台常驻；联机需电脑开房/中继（手机可加入）。详见 [MOBILE.md](MOBILE.md)

## ⚙️ 联机说明

- **一键创建**：联机大厅直接点「创建房间」，中继地址自动取当前电脑地址，无需手填；
- **两种加入方式**：输入 5 位房间号，或手机扫二维码（带 `?room=` 会自动进房）；
- **复制邀请链接**：房主可一键复制 `http://局域网IP:3000/?room=房间号`；
- 房主运行引擎并广播状态；不足座位由 AI 补齐；
- **观战**：在联机大厅输入房间号点「观战加入」，观战者不占座位、只读公共视图（手牌隐藏），可看全部玩家/装备/判定/日志与特效；
- 高级玩家仍可在「高级设置 · 中继服务器」里改地址；
- 手机建议横屏；联机客户端不能发动主动技能（房主可）。

## ⚠️ 已知限制

- 无懈可击支持“无懈互相抵消链”（受影响方与来源方交替出牌）；AOE 锦囊被无懈时仍整张取消，不逐个目标抵消；
- 寒冰剑/青龙偃月刀/贯石斧对真人会弹出“是否发动”确认；AI 自动发动；
- 联机不支持断线重连/旁观/公网房间列表；房主离开解散房间；联机暂为自由混战，组队模式与「允许攻击队友（误伤）」目前仅单机开放（序列化已带 team/teamMode/friendlyFire 字段，便于后续扩展）；
- AI 会按局势发动制衡/仁德/武圣，并主动使用乐不思蜀、兵粮寸断、闪电；但不会评估所有自定义主动技，联机客户端自定义主动技仍受限；
- 《名将杀》式多身份、埋伏牌等深度玩法仍在路线图；
- 卡牌编辑器尚未实现；武将立绘需自行填写图片路径。
